# KIZUNA
One-page website for The Kizuna Co. (@thekizunaco): proposals, birthdays and anniversaries.

## Run it
Open `index.html` in a browser, or serve the folder:

    python3 -m http.server 8000

## Files
- `index.html`  page content
- `styles.css`  all styling and animations
- `script.js`   falling petals, scroll reveal, cursor sparkles
- `assets/`     logo and team photos (swap files, keep the names)

Fonts (Cormorant Garamond, Great Vibes, Outfit) load from Google Fonts.
